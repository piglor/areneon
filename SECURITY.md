# Security Policy

Areneon is pre-alpha; there are no supported releases yet.

Please report vulnerabilities **privately** through GitHub's
[private vulnerability reporting](https://github.com/piglor/areneon/security/advisories/new).
Do not open a public issue.

In scope: leaks of private team data or opponent hidden information, the browser extension, the local loopback service, and supply-chain issues.

Never include real private teams, credentials or battle logs from other players in a report.
