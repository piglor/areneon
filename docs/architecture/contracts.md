# Contracts and fixtures

The ADR-008 contract profile, the generated TS and pydantic types, the shared sample corpus and the fixtures rules.

Part of the architecture documentation split out of `CLAUDE.md` (index: [README](README.md)). Ticket references such as `#1179` point to Redmine (`redmine.piglor.com/projects/areneon`), where measured figures and verdicts are recorded.

**Polyglot monorepo** (ADR-002): TypeScript in `packages/*` (pnpm workspace), Python in `scripts/` and `tests/` today plus the generated-contracts package `packages/schema/python` (a uv workspace member next to its schemas; `ml/` for the policy worker in `ml/areneon_ml/worker` (the networks follow), `services/` later), Rust in `crates/` once the first crate lands. `packages/schema` holds the JSON Schema contracts: the rules records (`rules/`, ADR-007) and the cross-language contracts (`contracts/v<N>/`, ADR-008), from which the TS types in `generated/ts/` and the pydantic models in `python/areneon_contracts/models/` (the `areneon-contracts` uv workspace package, `scripts/contract_models.py`) are generated and checked in; serde follows with the first crate. On Python, `areneon_contracts.contracts` validates with python-jsonschema, then parses into the model (`parse`), and hashes with RFC 8785 (`jcs`, `request_hash`). `fixtures/contracts/` is the shared sample corpus (valid and invalid instances of every contract, plus `reader-invalid/` ones that pass the schema and that a TS reader such as `readEpisode` refuses, plus their JCS digests in `hashes.json`, whose keys are sorted by path so a rebuild never reorders them: `samples.test.ts` holds the committed file byte for byte equal to a fresh capture, #1298): Ajv and python-jsonschema must classify it identically and every language must reproduce the digests. A contract's `$id` (`urn:areneon:schema:<contracts|engine>:v<N>:<name>`) declares its profile, and `src/profile.ts` enforces it as a keyword whitelist: closed objects, bounded integers, local `$ref`s, `kind`-tagged `oneOf`; `engine` schemas, which copy the pinned engine's wire shapes, also allow scalar type unions and get their own Ajv instance (`src/ajv.ts`). `Provenance` gained the optional `collection` as a minor change within v1 (ADR-008 §3): a reader older than it rejects such an Episode, so the generated types and models ship with the schema change. `make contracts` fails on a profile violation or on generated types that differ from a fresh run.

**Fixtures** live only under `fixtures/` (CC0, synthetic or sanitized, with provenance). `fixtures/showdown/<format>/` holds the golden request fixtures plus `battle.summary.json` (the log hash and choices), `channels/p1.json` and `p2.json` (each player's own stream of the golden battle as a `PlayerChannelLog`, the only battle input an observation may be built from), and `choices/` the choice corpus. `random/` is the random-play channel corpus (`b00.json`..., each a seed, the two synthetic teams, the actor seeds and both players' `PlayerChannelLog`, plus `manifest.json`). `fixtures/teams/<format>/` holds synthetic PokePaste teams, a `manifest.json` (provenance, expected verdict and reason) and `verdicts.json` (the validator's log). CI re-captures and compares the request fixtures, summary and verdicts, so engine behaviour drift fails the build. Pastes keep Showdown's trailing spaces (`.editorconfig`, `.gitattributes`).
